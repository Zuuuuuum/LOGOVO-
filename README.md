# LOGOVO — сайты барбершопа и школы

Два сайта сети мужских парикмахерских LOGOVO (Новосибирск):

- **Главная** — лендинг барбершопа: услуги и цены, мастера, работы, отзывы, три салона, запись через YClients
- **Школа** (`/school/`) — страница школы барберов: программы курсов, тренеры, ученики, заявка на обучение

## Просмотр локально

Любым статическим сервером, например:

    python -m http.server 8000

и открыть http://127.0.0.1:8000/

## Публикация на GitHub Pages

1. Создайте на GitHub новый репозиторий (Public) и загрузите файлы этой папки
   (Add file → Upload files, можно перетащить папку целиком).
2. В репозитории: Settings → Pages → Source: Deploy from a branch → Branch: main, папка / (root) → Save.
3. Через 1–2 минуты сайт доступен по адресу вида `https://<пользователь>.github.io/<репозиторий>/`

Страница школы будет по адресу `.../<репозиторий>/school/`.

## Структура

    index.html          — главная
    school/index.html   — школа
    css/, js/           — стили и скрипты
    assets/             — фото и графика
    pages/              — политика конфиденциальности и согласие
